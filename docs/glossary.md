# 术语表（Glossary）

> 面向熟悉编程但不太熟悉金融和统计的读者。按主题分组，每个术语注明首次出现在哪个 qtc 课程阶段，方便回顾。

## 量化研究

| 术语 | 解释 | qtc |
|---|---|---|
| **Alpha** | 扣除市场整体涨跌（beta）之后的超额收益。量化研究的目标就是找到稳定的 alpha 来源 | P7 |
| **因子（Factor）** | 给每只股票在每个时点打一个分数的公式，例如“过去 20 日波动率的相反数”。截面因子比较的是同一天内不同股票的相对高低 | P7 |
| **截面（Cross-section）** | 同一个时点、所有股票组成的一组数据。截面因子只看股票之间的相对排序 | P7 |
| **IC（Information Coefficient）** | 某天的因子值与之后一段时间收益的（秩）相关系数。IC 均值大于 0 说明因子有预测力 | P7 |
| **ICIR** | IC 均值除以 IC 标准差，衡量预测力是否**稳定** | P7 |
| **分层回测（Quantile backtest）** | 按因子值把股票分成 N 组，比较各组收益是否单调 | P7 |
| **TopN 组合** | 每次调仓买入因子值最高的 N 只股票 | P8 |
| **换手率（Turnover）** | 每次调仓需要交易的仓位比例。换手越高，成本越高 | P4/P8 |
| **中性化（Neutralization）** | 把因子对行业或市值做回归、取残差，剔除“其实只是在押某个行业或押小盘股”的成分 | P7 |
| **MAD 去极值** | 用中位数绝对偏差截断极端值，防止少数异常值主导结果 | P7 |
| **容量（Capacity）** | 策略能容纳多少资金而不被冲击成本吃掉收益 | P11/P14 |

## 统计与过拟合

| 术语 | 解释 | qtc |
|---|---|---|
| **p 值** | 假设因子其实没用，观察到当前（或更极端）结果的概率。越小越不像是巧合 | P3 |
| **多重检验（Multiple testing）** | 试了 100 个因子，即使全都无效，也会有约 5 个碰巧 p<0.05。试得越多，越需要校正 | P3/P10 |
| **Holm 校正** | 控制“至少有一个误报”的概率（FWER）。比较严格 | P10 |
| **BH 校正（Benjamini–Hochberg）** | 控制“报出来的结果中误报的比例”（FDR）。比较宽松 | P10 |
| **夏普比率（Sharpe Ratio, SR）** | 年化收益除以年化波动，衡量单位风险对应的收益 | P4 |
| **DSR（Deflated Sharpe Ratio）** | 考虑到“试了很多次才挑出这个最好的”之后，对夏普比率做的折扣。DSR 接近 1 才可信 | P10 |
| **PSR（Probabilistic Sharpe Ratio）** | 真实夏普比率大于某个基准值的概率 | P10 |
| **Trial** | 一次接触了数据的评估。trial 次数是多重检验校正的分母，AlphaPilot 在全局累计 | P10 |
| **过拟合（Overfitting）** | 模型或因子记住了历史噪声，而不是学到了规律，到了样本外就失效 | P3/P9 |

## 样本切分与偏差

| 术语 | 解释 | qtc |
|---|---|---|
| **IS（In-Sample）** | 样本内，即研究阶段可以随便看的数据 | P4 |
| **Embargo（隔离带）** | 在 IS 和 HOLDOUT 之间留一段空白，防止收益计算窗口跨越边界、造成信息泄漏 | P9 |
| **HOLDOUT（留出集）** | 研究阶段看不到、只在最后检验一次的数据。看过多次就不再是“留出”了 | P4/P10 |
| **FORWARD** | 批准之后的真实时间，是唯一真正的样本外 | P13/P14 |
| **前视偏差（Look-ahead bias）** | 在 t 时刻用到了 t 之后才能知道的信息。AlphaPilot 用 `lookahead_test` 截断未来数据，检验因子值是否会变 | P1/P10 |
| **幸存者偏差（Survivorship bias）** | 只用“现在还在”的股票做研究，忽略了已经退市的股票，会高估收益 | P1 |
| **知识截止日污染** | LLM 的训练数据覆盖了某段行情，它提出的“想法”可能暗含对未来的了解，所以这段时间的 HOLDOUT 只能算 PSEUDO_OOS | P10 |
| **Evidence Level** | AlphaPilot 的证据等级：IS < PSEUDO_OOS < TRUE_OOS | — |

## A 股市场规则

| 术语 | 解释 | qtc |
|---|---|---|
| **T+1** | 当天买入的股票要到下一个交易日才能卖出 | P1/P13 |
| **涨跌停** | 单日涨跌幅上限：主板 ±10%；创业板（代码以 30 开头）和科创板（688 开头）±20%；北交所 ±30%；主板 ST 自 2026-07-06 起也是 ±10% | P1 |
| **一手** | 买入的最小单位是 100 股 | P1 |
| **复权** | 分红、送股之后，用复权价消除价格的断层。**收益只用新浪的等比复权**；东财的 qfq/hfq 是加减法复权，除息日的收益会失真 | P1 |
| **印花税** | 卖出时征收（目前为 0.05%） | P4 |
| **停牌** | 暂停交易期间既不能买也不能卖，回测中必须处理 | P1/P4 |

## 工程与 AI

| 术语 | 解释 |
|---|---|
| **LangGraph** | 用状态图编排 LLM 应用的框架，支持条件分支、循环、中断（interrupt）和持久化（checkpoint） |
| **interrupt / resume** | 图执行到审批节点时暂停，并把状态存入数据库；人做出决定后，用 `Command(resume=...)` 从断点继续 |
| **MCP（Model Context Protocol）** | 让 LLM 应用以标准方式调用外部工具和数据的协议。AlphaPilot 把量化工具做成 MCP server，Claude Code 等客户端可以直接调用 |
| **ReAct** | 让模型交替进行“推理”和“调用工具”的 Agent 模式。AlphaPilot 只在 plan 节点使用有限步数的 ReAct |
| **HITL（Human-in-the-loop）** | 关键决策由人做出 |
| **Faithfulness（忠实度）** | 报告内容是否忠于事实来源，有没有编造 |
| **DSL（领域专用语言）** | AlphaPilot 的因子表达式语言，例如 `rank(-ts_std(ret, 20))`。用 AST 白名单校验，不调用 eval |
| **canonical_hash** | 把 DSL 表达式规范化（如交换律排序）之后计算的哈希，用来识别“写法不同但本质相同”的表达式 |
| **thinking / reasoning_effort** | DeepSeek V4 的思考模式开关和强度。开启后模型先输出思维链（`reasoning_content`），再输出答案 |
| **ADR** | 架构决策记录，见 `docs/adr/` |
